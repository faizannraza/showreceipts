## Overriding and pinning

- `--prices <file>` replaces the built-in table for one run; a user override
  file at `~/.showreceipts/prices.json` applies everywhere except `demo`.
- `--as-of YYYY-MM-DD` prices everything at that date's rates instead of the
  per-call day.
- `doctor` warns when a model in your sessions has no price row
  (`unpricedModels`) or when an unverified row is in use — the receipt marks
  those costs with `≈` and never silently guesses.

The cost line is always **API-equivalent**: what the logged usage would cost
at list prices. Subscription users pay their plan, not this number (Codex
plan usage is shown alongside when the rollout records it).
